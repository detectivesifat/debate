# Format Style of the Debate Script

This document follows a standard **Reasoning – Example – Linking** case-construction structure, commonly used in Asian Parliamentary–style debate prep to build a single argument fully before moving to the next.

## 1. Claim Header (Implicit Thesis Statement)
The title itself functions as the argument's core claim, stated as a complete, standalone assertion rather than a topic label — phrased so it could be read aloud as the first line of a speech.

## 2. Reasoning Section
- Opens with a general mechanism claim ("Life skills are not developed in isolation").
- Moves to a concrete illustrative case (debate) before the evidence-based example — a *mini-example inside the reasoning*, distinct from the main cited study later.
- Uses a numbered progression of impacts ("Second... Third..."). There is no explicit "First" — the numbering starts at the second logical step, with the opening paragraphs functioning as the implicit first point.
- Each step builds causally on the last (learning → application → real-world functioning): a chain-logic structure rather than parallel independent points.
- Closes with a "Therefore" sentence that restates the full claim, mirroring the opening title almost verbatim and bookending the section.

## 3. Example Section
- Follows a fixed citation-first pattern: source credibility (researchers, journal, peer-review status) is established *before* the finding itself.
- Structured as: institution/context → methodology (sample size, method, comparison groups) → intervention detail (what PBL actually involved) → assessment method → result.
- Ends with a full academic citation block (authors, journal, volume, pages, DOI), formatted like a works-cited entry rather than integrated into prose.
- No direct quotation from the study is used anywhere — everything is paraphrased/summarized.

## 4. Linking Section
- Explicitly reconnects the example back to the Reasoning section's exact vocabulary ("life skills," "theoretical knowledge," "practical activities") — a deliberate lexical echo, not just conceptual repetition.
- Uses a concession-and-rebuttal micro-structure: "The Government may present X... But this example shows Y" — anticipating the opposing bench's framing before dismantling it.
- Ends by repeating the thesis sentence a *third* time (title → end of Reasoning → end of Linking), verbatim.

## Overall Stylistic Traits
- Heavy use of transitional signposting words as paragraph openers (Therefore, So, But, Second, Third, More importantly) — built for oral delivery/signposting in a timed speech, not silent reading.
- Sentence-level rhythm: short declarative sentences alternating with one longer explanatory sentence per paragraph.
- No first-person framing ("I argue") — fully third-person/impersonal register typical of competitive debate case-writing.
- The three-part structure (Reasoning/Example/Linking) is a named, standard case-construction unit in competitive debate coaching — this script is essentially one complete "argument block" of that kind, likely meant to be one substantive point within a larger constructive speech.
